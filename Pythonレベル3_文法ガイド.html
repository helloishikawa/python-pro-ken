1変数の型（int・String・boolean）

値には「型（しゅるい）」があります。レベル3では、この3つと、型が混ざったときの注意がよく問われます。
int（整数）100 や 0、-5 など。計算できる数。
String（文字列）"こんにちは" のように " で囲む。文字。
boolean（真偽値）True（真）と False（偽）。条件の結果。

正しい書き方

age = 15              # int（数）
name = "たろう"       # String（文字列。" で囲む）
is_member = True      # boolean（True か False）

print(age)            # 15
print(name)           # たろう
print(is_member)      # True
出力： 15 / たろう / True

型が混ざるときの注意（レベル3の重要ポイント）

score = 90

# print("点数は" + score)          # ← エラー（文字 + 数はできない）
print("点数は" + str(score) + "点")   # 数を文字にしてつなげる → 点数は90点

a = "22"
b = "10"
print(a + b)          # "22"+"10" は文字の連結 → 2210
print(int(a) + int(b))# 数にしてから計算 → 32
出力： 点数は90点 / 2210 / 32

「文字の "True"／"False"」と「本当の True／False」は別物

flag = "False"        # これは"文字列"（booleanのFalseではない）

if flag:              # 中身のある文字列なので "真" 扱い
    print("実行されます")
else:
    print("実行されません")
出力： 実行されます
つまずきポイント：
  • 文字と数は そのまま + できない。表示でつなぐなら str()、計算するなら int()。
  • if の条件では、中身のある文字列や 0 以外の数は「真(True)扱い」、空文字 "" や 0、False は「偽(False)扱い」。
  • "True"・"False"（" で囲む）は文字列。中身があるので if は成立する。本当の真偽値は クォート無しの True／False。

2乱数（random）

ランダムな値を作る機能です。検定では次の2つがセットでよく出ます（問題文にも説明が付きます）。
random.random()0以上1未満のランダムな小数（例：0.73）。
math.floor(num)小数点以下を切り捨てて整数にする（例：5.9→5）。

正しい書き方（1〜6 のランダムな整数＝サイコロ）

import random
import math

dice = math.floor(random.random() * 6) + 1
print(dice)
出力： 1〜6 のどれか
random.random()0以上1未満の小数（例 0.73）。
... * 60以上6未満（0〜5.99…）にひろげる。
math.floor(...)切り捨てて 0〜5 の整数にする。
... + 11〜6 にずらす。
つまずきポイント：
  • 「1〜N のランダムな整数」は math.floor(random.random() * N) + 1 が基本形。
  • かける順番に注意。math.floor(random.random()) * 6 は、先に切り捨てて 0、×6 でも いつも 0 になってしまう。* 6 は floor の中に入れる。
  • random.random() だけでは 0〜0.99… の小数。整数にするには * N と math.floor が必要。

3関数（def・引数・戻り値 return）

よく使う処理に名前を付けてまとめたものが「関数」。def で作り、return で結果を返します。レベル3で特に多い分野です。

正しい書き方

def add_tax(price):        # price は「引数」（受け取る値）
    return price + 100     # return で結果を返す

total = add_tax(500)       # 500 を渡す → 600 が返る
print(total)
出力： 600
def add_tax(price):関数 add_tax を作る。() の中の price が受け取る値（引数）。
return price + 100price+100 の結果を「返す」。
total = add_tax(500)500 を渡して呼ぶ。返ってきた 600 が total に入る。
つまずきポイント：
  • 関数は「作る（def）」だけでは動かない。「呼ぶ（名前()）」で初めて実行される。
  • 引数の数を合わせる（def add_tax(price) なら1つ渡す）。渡し忘れ・渡しすぎはエラー。
  • return を書かないと結果は返らない（None になる）。
  • 関数の中で作った変数は外では使えない。外で使いたいなら return で返す、または print を関数の中で行う。

4for（配列の処理）

複数の値をまとめた「リスト（配列）」を、for で1つずつ処理します。合計や個数を求める問題がよく出ます。

正しい書き方（リストの合計）

prices = [200, 500, 300]
total = 0

for price in prices:        # 1つずつ price に取り出す
    total = total + price    # 合計に足していく

print(total)
出力： 1000
prices = [200, 500, 300]3つの数が入ったリスト。
total = 0合計を 0 から始める。
for price in prices:リストから1つずつ price に取り出してくり返す。
total = total + price取り出した値を合計に足す。200+500+300＝1000。

番号で取り出す・個数を数える（参照と len）

fruits = ["りんご", "みかん", "ぶどう"]

print(fruits[0])            # 番号で参照（番号は0から）→ りんご
print(len(fruits))          # 個数 → 3

for i in range(0, 3):       # 0,1,2 と数を1つずつ
    print(fruits[i])        # 番号を使って順番に取り出す
出力： りんご / 3 / りんご / みかん / ぶどう
fruits[0]番号で1つ取り出す。番号は 0から（0番目＝りんご）。
len(fruits)リストの個数（要素の数）を返す。→ 3。
for i in range(0, 3):i を 0,1,2 と変えながら、番号で順番に取り出す。
つまずきポイント：
  • 番号は 0から。3個のリストの番号は 0・1・2。存在しない番号（例 fruits[3]）はエラー。
  • range(0, 3) は 3 を含まない（0,1,2 の3回）。
  • 合計は total = 0 から始めて、for の中で足す。文字の数字リスト（例 ["80","90"]）を合計するときは int() で数にしてから足す。
