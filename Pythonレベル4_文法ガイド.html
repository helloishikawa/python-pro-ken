1定数（const）

定数とは「一度決めたら、あとから変えられない値」のこと。検定では import const を書いて、const.名前 = 値 の形で定義します。

正しい書き方

import const

const.TAX = 10          # ← 定数を「定義」する（最初の1回だけ）

price = 200             # ← 変化させたいものは"普通の変数"にする
price = price + const.TAX   # 普通の変数は変更OK。定数は"使うだけ"
print(price)
出力： 210
import const定数を扱う機能を読み込む。
const.TAX = 10定数 TAX を 10 で定義。定数名は大文字で書くのがふつう。
price = 200後で変えたい値は、定数ではなく普通の変数にする。
price = price + const.TAX定数 TAX は"読むだけ"。計算結果は普通の変数 price に入れる。
つまずきポイント：定数は「定義（最初の代入）」はOKだけど、あとから const.TAX = const.TAX + 1 のように書き換えるとエラー。合計・カウントなど“変化していく入れ物”には、必ず普通の変数を使う。

2switch ＝ match / case 文

他の言語の「switch」にあたる、値による分かれ道です。Pythonでは match と case を使います。

正しい書き方

signal = "赤"

match signal:
    case "赤":
        print("止まれ")
    case "青":
        print("進め")
    case _:
        print("注意")
出力： 止まれ
match signal:signal の中身で分かれる。match のあとに“調べる値”を書く。
case "赤":signal が "赤" のとき…「止まれ」。
case "青":signal が "青" のとき…「進め」。
case _:_ は「上のどれにも当てはまらないとき（＝その他すべて）」。
つまずきポイント：
  • match signal: の“調べる値”を忘れない（match: だけはNG）。
  • 分かれ道は if ではなく case を使う。
  • case value == "赤": のように“条件式”を書くのは誤り。case の後ろには“値そのもの（パターン）”を書く（例：case "赤":）。

3配列（リスト）の操作：参照・追加・削除

複数の値をまとめて入れる箱が「リスト（配列）」。番号は 0 から数えます。

正しい書き方

fruits = ["りんご", "みかん", "ぶどう"]

print(fruits[0])          # 参照：0番目 → りんご
print(fruits[2])          # 参照：2番目 → ぶどう

fruits.append("もも")     # 追加：末尾に「もも」を足す

fruits.remove("みかん")   # 削除：値「みかん」を消す
del fruits[0]             # 削除：0番目（りんご）を消す

print(fruits)
出力： りんご / ぶどう / ['ぶどう', 'もも']
fruits = [...]3つの値が入ったリストを作る。
fruits[0]参照。番号で1つ取り出す。0番目＝りんご、2番目＝ぶどう。
fruits.append("もも")追加。.append(値) で末尾に足す。
fruits.remove("みかん")削除（値で）。.remove(値) はその値を探して消す。
del fruits[0]削除（番号で）。del リスト[番号] はその場所を消す。
つまずきポイント：
  • 番号は 0から。3個のリストの番号は 0・1・2。存在しない番号（例：fruits[3]）を参照するとエラー。
  • remove は“値”で消す、del は“番号”で消す。取り違えに注意。
  • （参考）リスト.pop(番号) は「取り出しながら削除」。len(リスト) は個数。

4while 文（条件がTrueの間くり返す）

while 条件: は、条件が成り立っている間ずっとくり返します。

正しい書き方

count = 1

while count <= 3:
    print(count)
    count = count + 1      # ← これを忘れると永遠に終わらない

print("おわり")
出力： 1 / 2 / 3 / おわり
count = 1数える変数を1から始める。
while count <= 3:count が 3 以下の間くり返す。
print(count)今の count を表示。
count = count + 1count を1増やす。これで、いつか条件が False になって止まる。
つまずきポイント：くり返しの中で 条件をいつか False にする更新（count = count + 1 など）を忘れると、永遠に止まらない「無限ループ」になる。
for は「回数が決まっている」くり返し、while は「条件しだい」のくり返し、と覚えると使い分けやすい。

5ループの中断・継続：break / continue

くり返しの流れを変える2つの命令です。break＝もうやめる、continue＝この回だけとばす。

break（くり返しを途中でやめる）

for i in range(1, 6):
    if i == 3:
        break
    print(i)
出力： 1 / 2　（3になった瞬間にくり返しごと終了）

continue（その回だけとばして次へ）

for i in range(1, 6):
    if i == 3:
        continue
    print(i)
出力： 1 / 2 / 4 / 5　（3のときだけ print をとばす）
つまずきポイント：
  • break：残りのくり返しを全部やめてループの外へ出る。
  • continue：その1回だけスキップして、次のくり返しに進む（ループは続く）。
  • どちらも while でも使える。同じ形で「途中でやめる／とばす」ができる。
ここからは基礎の復習（レベル1〜3の内容だが、レベル4の問題にもよく出ます）

6for 文 と range

for は「決まった回数」や「リストの要素の数だけ」くり返すときに使います。

正しい書き方

fruits = ["りんご", "みかん", "ぶどう"]

for fruit in fruits:      # リストの中身を1つずつ取り出す
    print(fruit)

for i in range(0, 3):     # 0, 1, 2 と数を1つずつ
    print(i)
出力： りんご / みかん / ぶどう / 0 / 1 / 2
for fruit in fruits:リストから1つずつ fruit に取り出してくり返す。
for i in range(0, 3):i を 0,1,2 と変えながらくり返す（3回）。
つまずきポイント：range(0, 3) は 3 を含まない（0,1,2 の3回）。
「回数・要素の数だけ」なら for、「条件が続く間」なら while（→ 4番）と使い分ける。for (条件): という書き方は誤り。

7if / elif / else（条件分岐）

条件によって処理を分けます。上から順に調べ、最初に当てはまった1つだけを実行します。

正しい書き方

score = 70

if score >= 80:
    print("合格")
elif score >= 60:
    print("あと少し")
else:
    print("不合格")
出力： あと少し
if score >= 80:80以上なら「合格」。今回は70なので当てはまらない。
elif score >= 60:（ifが外れたら）60以上なら「あと少し」。70なのでここ。
else:どれにも当てはまらないとき「不合格」。
つまずきポイント：分岐は if →（必要なら）elif（何個でも）→ else の順。else に条件は付けない。上から順に見て、当てはまった時点で残りは調べない。

8関数（def・引数・戻り値 return）

よく使う処理に名前を付けてまとめたものが「関数」。def で作り、return で結果を返します。

正しい書き方

def add(a, b):        # a, b は「引数」（受け取る値）
    return a + b      # return で計算結果を返す

answer = add(3, 5)    # 3 と 5 を渡す → 8 が返る
print(answer)
出力： 8
def add(a, b):関数 add を作る。() の中の a,b が受け取る値（引数）。
return a + ba+b の結果を「返す」。
answer = add(3, 5)3と5を渡して呼ぶ。返ってきた8が answer に入る。
つまずきポイント：
  • 引数の数を合わせる（def add(a, b) なら呼ぶときも2つ渡す）。
  • return を書かないと結果は返らない（None になる）。
  • 関数の中で作った変数は、関数の外では使えない。

9型変換（str・int）と文字列の連結

文字と数は種類がちがうので、混ぜるときは変換します。str()＝数を文字に、int()＝文字を数に。文字どうしは + でつなげます。

正しい書き方

count = 3
print("残り" + str(count) + "個")   # 数を文字にしてつなげる

price = "500"
total = int(price) + 100            # 文字を数にして計算
print(total)
出力： 残り3個 / 600
"残り" + str(count) + "個"count(数の3)を str() で文字"3"にしてから連結。→「残り3個」。
int(price) + 100price(文字"500")を int() で数500にして計算。→ 600。
つまずきポイント：文字と数は そのまま + できない（"残り" + 3 はエラー）。表示でつなげたいときは str() で文字にそろえ、計算したいときは int() で数にそろえる。

10リストに「含まれるか」を調べる（in）

値 in リスト と書くと、その値がリストの中にあるかを True / False で調べられます。

正しい書き方

menu = ["マグロ", "サーモン", "エビ"]

if "サーモン" in menu:
    print("あります")
else:
    print("ありません")
出力： あります
"サーモン" in menumenu の中に "サーモン" があるか調べる → ある(True)。
if ... : / else:あれば「あります」、なければ「ありません」。
つまずきポイント：if menu: は「リストが空でないか」を見るだけ（中身が1つでもあれば、いつも True）。
「特定の値があるか」を調べたいときは、必ず 値 in リスト を使う。
